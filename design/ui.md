# 游戏 UI 设计

## 关卡内

### 场景设置

入口墙上需要有大字：“嚼得菜根，做得大事”。

### 界面元素

- 使用 emoji 表示学生 🍚🥬🥩, 窗口 🪟, 汤碗 🥣 等。横向堆叠表示剩余量。
- 玩家是食堂经营者，不是学生。
- 有多个窗口：
  - 大伙窗口 (self-service, 荤菜按重量收费 + 蔬菜菜品)。
  - 特色窗口 (set meals, 固定价格)。（暂时不做）
- 学生 (AI 智能体) 成波次进入，排队，打菜，就餐，给出可视化满意度反馈 (emojis like 🙂😡🤢 for satisfaction)。
- 满意度取决于：
  - 定价公平性 (太高 → 😡)。
  - 食物可用性 (窗口关闭 → 🙁)。
  - 随机安全事件 (变质菜 → 🤢)。
  - 😁🙂🤮
  - ...

- **人物**：随机学生 emoji（候选池： 👩‍🎓 🧑‍🎓 👨‍🎓 👧 👦）。
- **菜品**：🥩（肉）、🍛（菜）、🥣/🍲（汤）、🧴（可疑物）、🍽️（盘子）。
- **表情反馈**：🙂 😐 😡 🤮（emoji 文本或小图）。
- SFX：秤嘀嗒、收银机叮、呕吐声（夸张卡通化）、群嘈音。

### GUI

- 顶部：关卡当前状态，包括钱，时间，收入等

屏幕分区：左侧场景（学生流动与窗口），右上/右侧控制面板（玩家控制），下方信息栏（日志/利润/平均满意度）。

- 实时信息：
  - 当前利润 ¥
  - 当前就餐人数
  - 平均满意度（数值 + emoji）
  - 角色反馈直接在人物头顶冒出气泡，短暂显示后消失，不设统一日志面板
